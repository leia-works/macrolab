# MacroLab

マウスとキーボードの操作を、設定したとおりに繰り返す Windows 向けのツール。

**いちばんの特長は、連打の速さと、一覧の中だけで直せる使いやすさ。**

## ダウンロード

最新版は [Releases](https://github.com/leia-works/macrolab/releases) から。

- **MacroLab-1.1.0-standalone.zip**（52MB）… そのまま動く。迷ったらこちら
- **MacroLab-1.1.0-dotnet9.zip**（0.5MB）… .NET 9 デスクトップランタイムが入っている方向け

動作環境＝Windows 10 / 11（64bit）

## 速さ

### 待ち時間の丸めに対処した

**Windows の待機は、既定でおよそ 15.6ms 刻みに丸められる。**
待ち時間を 0 と書いても1手ごとに待たされるので、8手の連打で約125ms＝60fps のゲームで7フレームぶんになる。

**MacroLab の対処**＝実行中だけタイマーの分解能を上げ、
「長い間は寝て、最後の2ミリ秒だけ空回しする」ハイブリッドの待ち方にした。

実測: **1ms 待機の平均ずれ 0.009ms ／ すきま 0 の設定で 50手が 2.2ms**。

⚠️ 既定では、待ち時間 0 の行にも 10ms のすきまを空けている（受け取る側の取りこぼしを防ぐため・下の「待ち時間 0 の行」）。
最速で撃ちたい時は、設定ですきまを 0 にする。

### クリックする場所がずれない

**マルチモニタ環境では、座標の基準が食い違うとクリック位置がずれる。**

Windows にマウスの位置を伝えるとき、座標は 0〜65535 の値に直して渡す。
このとき「何を基準に直すか」に2通りあって、

- プライマリモニタだけを基準にする
- 全モニタを合わせた範囲（仮想スクリーン）を基準にする

**この2つが食い違うとクリック位置がずれる。**

実測（2026-08-28・4画面／仮想スクリーン 6400x1800 に対しプライマリ 2560x1080）:

| 指定した座標 | 基準を間違えた時に実際に押される場所 | ずれ |
|---|---|---|
| (1955, 801) | (2969, 1335) | +1014, +534 |
| (2370, 740) | (4006, 1234) | +1636, +494 |

⚠️ 1画面だけの環境では両者が一致するので、この食い違いは起きない。

**MacroLab の対処**＝内部の座標をすべて仮想スクリーン基準に統一し、
`MOUSEEVENTF_ABSOLUTE | MOUSEEVENTF_VIRTUALDESK` を必ず両方立てて送る。

## 使いやすさ

**いつも通り操作して記録し、一覧の中で動作と待ち時間を直すだけ。**
右のパネルとの行き来が要らないので、ふだんは「簡易」の表示で足りる。

| 機能 | 説明 |
|---|---|
| **操作の記録** | 実際にクリック・入力すると、そのまま行になる。待ち時間も実測で入る |
| **一覧の中で直す** | なにをする・座標・キー・待ち時間を、その場で打ち直せる |
| **ウィンドウ基準の座標** | ウィンドウを動かしても壊れない |
| **中クリック** | 左右のクリックに加えて送れる |
| **選んだ行だけ試す** | 1行だけ実行して確かめられる |
| **一時停止** | 止めずに中断して、続きから再開できる |
| **最後の停止キー** | `Ctrl + Shift + Alt + F12`。**設定でつぶせない** |
| **簡易 / 詳細** | ふだんは一覧だけ。細かい設定が要る時だけ切り替える |
| **どこにいても効くキー** | ほかのアプリを触りながら実行・停止できる（メニュー ▸ 設定） |
| **保存の確認** | 変更があるまま閉じようとすると確かめる |

## 使い方

### 起動

`MacroLab.exe` をダブルクリック。ファイルを引数に渡せば、そのまま開いた状態で始まる。

```
MacroLab.exe "C:\path\to\マクロ.mlab"
```

`.mcrn` / `.mlab` を右クリック →「プログラムから開く」でも使える。

### 簡易 / 詳細

上のタブで切り替える。設定は覚えるので、次に開いた時も同じ表示で始まる。

| | 簡易 | 詳細 |
|---|---|---|
| 一覧の中で直す（なにをする・座標・キー・待ち時間） | ○ | ○ |
| 繰り返しと終わり方 | ○ | ○ |
| 座標の基準（画面 / ウィンドウの中） | − | ○ |
| 送る相手のウィンドウ | − | ○ |
| この行だけ試す・名前を付けて保存 | − | ○ |

### 行を作る

3つのやり方がある。

1. **操作を記録**（いちばん速い）— ボタンを押すと記録が始まる。いつも通り操作して、
   終わったら**「記録を終える」ボタン**（`Ctrl + Shift + F12` でも可）。
   ⚠️ **記録ウィンドウの上でのクリックは記録されない**ので、ボタンを押してもマクロに混ざらない。
2. **「拾う」ボタン** — 一覧の各行にある。座標を使う行なら画面から拾い、キーの行ならキー入力を待つ。
   ⚠️ 拾う時のクリックは下のアプリに届かないので、間違って押してしまう心配はない。
3. **手で入れる** — 一覧の下のボタンで追加して、一覧の中で直接打ち込む。

**行を足すボタンは2つある**（どちらも押す前に入る場所が分かるようにしてある）:

- **＋ 一番下に足す** — いつでも一覧のいちばん下に足す。
- **＋ 選んだ行の次に足す** — 選んでいる行のすぐ下に差し込む。選んでいない時は押せない。
- **選んだ行を複製** — 選んでいる行と同じ中身の行を、すぐ下に作る。

**並べ替え**は、行の左端にある**点々のつまみ**（番号の左）を掴んで動かす。
**いちばん下の行より下**へ落とすと末尾に移る
（その時は最後の行の**下**に線が出る。行の上に落とす時は**上**に線が出る）。

⚠️ **入力欄・プルダウン・ボタンの上では掴めない**（文字の選択とプルダウンを壊さないため）。
実測すると行の幅の **69% が入力欄**なので、**つまみを使うのが確実**。

### 動かす

- **実行** で始まる（`Ctrl + Enter` でも）。**Esc** で止まる。
  ⚠️ 実行に `F5` は割り当てていない。ブラウザやエクスプローラーの「更新」と重なって、
  実行したいのに他のアプリが更新されてしまうため。
- 止まらない時は **`Ctrl + Shift + Alt + F12`**（この組み合わせは設定で変えられない）。
- 1行だけ確かめたい時は、その行を選んで「この行だけ試す」。

### 繰り返しと終わり方

`繰り返し` の数字は、`終わり方` の設定で意味が変わる。

| 終わり方 | 繰り返しの意味 |
|---|---|
| 回数で終わる | 何周するか |
| 秒数で終わる | 何秒間まわすか |

**0 は「止めるまでずっと」**。

### 待ち時間 0 の行

⚠️ **待ち時間を 0 にしても、少しだけ（既定 10ms）すきまが空く。**

間を空けずに撃つと、受け取る側のアプリやゲームが**入力を取りこぼす**。
「速いのに動かない」は、遅いより原因が見えにくい。

すきまは メニュー ▸ 設定 で変えられる。**0 にすれば元どおり最速**で撃つ。

実測: すきま 10ms なら 50手で 502ms（10.04ms/手）／すきま 0 なら 50手で 2.2ms。

## ファイルの形式

| 拡張子 | 読む | 書く | 備考 |
|---|---|---|---|
| `.mlab` | ○ | ○ | MacroLab の形式（JSON） |
| `.mcrn` | ○ | **×** | macroni の形式 |

⚠️ **`.mcrn` には書き戻せない。** 中クリック・ウィンドウ基準の座標・修飾キーは
macroni の形式では表現できないので、書き戻すと黙って情報が落ちる。
`.mcrn` を開いた時は `.mlab` での保存を促す。

## 気をつけること

- 🔴 **記録中はキーボードの入力がそのまま残る。パスワード欄では使わないこと。**
- 🔴 **通信は一切しない。**記録した内容が外に出ることはない。
- ⚠️ 管理者権限で動いているアプリには入力を送れない（Windows の仕組み）。
  その場合は MacroLab も管理者として実行する必要がある。届かない時はその旨を画面に出す。
- ⚠️ キーボードの入力を見張る仕組みを使うので、**ウイルス対策ソフトに疑われることがある**。
  そのため、フックは**必要な時だけ**掛けるようにしてある（記録中と、実行中の停止キー待ちだけ）。
- ⚠️ オンラインゲームでは、外部ツールによる自動操作を規約で禁止していることがある。使う場所は自己判断で。

## 設定の置き場

1. `MacroLab.exe` と同じ場所に `macrolab-settings.json` があれば、**そちらを使う**（持ち運び用）
2. 無ければ `%APPDATA%\MacroLab\macrolab-settings.json`

### 画面に出していない設定

設定ファイルに次の1行を足すと、設定画面に細かい項目が増える。

```json
"ShowAdvancedOptions": true
```

⚠️ ふだんは要らない項目（暴走の見張りなど）なので、既定では隠してある。
